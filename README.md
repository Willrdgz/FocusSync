📚 FocusSync

FocusSync es una aplicación móvil de productividad desarrollada con React Native y Expo que combina Inteligencia Artificial e Internet de las Cosas (IoT) para mejorar los hábitos de estudio. La aplicación utiliza Gemini API para generar planes personalizados según el tiempo disponible y las materias del usuario. Además, emplea los sensores del teléfono para detectar su posición, controlar el temporizador y registrar distracciones cuando el dispositivo es levantado durante una sesión. La autenticación, los planes y el historial se administran mediante Supabase.
